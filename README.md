# Wallpaper Slideshow

An Android live wallpaper that cycles through every picture inside a folder
you pick. Duration and transition effect are configurable in Settings.

## Features

* Pick any folder (SAF) - sub-folders are scanned recursively
* Duration per picture: 1 s ... 600 s
* Transitions: none, fade, slide-from-right, slide-from-bottom, zoom+fade
* Transition speed: 100 ms ... 5000 ms
* Optional shuffle
* Settings are applied live - no need to re-apply the wallpaper

## Building

The Gradle wrapper JAR is a binary file and is not generated by the
scaffolding script. Create it once with either of these:

    Option A - you already have Gradle installed:
        gradle wrapper --gradle-version 8.7

    Option B - just open the project folder in Android Studio,
               it will offer to generate the wrapper automatically.

Then:

    ./gradlew assembleDebug
    adb install -r app/build/outputs/apk/debug/app-debug.apk

## Usage

1. Open the app and tap "Pick picture folder".
2. Tap "Slideshow settings" to choose duration / transition / shuffle.
3. Tap "Set as live wallpaper" and confirm.

## Project layout

    app/src/main/java/com/example/wallpaperslideshow/
        MainActivity.kt                 - launcher screen, folder picker
        SettingsActivity.kt             - preference screen
        SlideshowWallpaperService.kt    - the live wallpaper engine
        ImageRepository.kt              - SAF folder scanner
        Prefs.kt                        - SharedPreferences accessor

    app/src/main/res/xml/preferences.xml  - settings definitions
    app/src/main/res/xml/wallpaper.xml    - live wallpaper descriptor
